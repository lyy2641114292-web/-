## Windows 快速启动
双击项目根目录的 `start.bat`。

也可以在 PowerShell 或命令提示符中运行：

```cmd
npm.cmd install
npm.cmd run dev
```

启动开发服务器或执行构建时，会自动检查并更新当天的开发日志。

## 当前完整原型流程
1. 首页介绍
2. 事件记录
3. 事实、判断、情绪与需求梳理
4. 冲突时间线回溯
5. 双视角转换
6. 视角对照与未知区域
7. 反思总结与完成页
