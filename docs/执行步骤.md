# Between Us 开发执行步骤

## 首次安装
1. 安装 Node.js 22 或更高版本。
2. 在项目根目录执行 `npm.cmd install`。
3. 双击 `start.bat`，或执行 `npm.cmd run dev`。
4. 浏览器访问 Vite 输出的地址，通常为 http://127.0.0.1:5174/。

## 日常开发
1. 阅读 CLAUDE.md 和相关 docs 文档。
2. 每次启动开发服务器或构建时自动检查当前日期日志。
3. 手动执行 `npm.cmd run log` 可立即创建或更新当天日志。
4. 完成事项记录到 dev-log/YYYY-MM-DD.md。
5. 修改代码后执行 `npm.cmd run lint` 和 `npm.cmd run build`。

## 模块开发顺序
1. 先完成首页与现有原型入口。
2. 再完善事件记录和事件梳理。
3. 进入时间线回溯模块。
4. 再实现双视角转换。
5. 实现视角对照与未知区域。
6. 最后实现反思总结和沟通表达草稿。

每个模块独立验收，不得因后续模块改变当前流程的核心原则。

## 页面验收
1. 检查空内容无法提交。
2. 输入冲突事件并进入梳理页。
3. 验证四个分类的编辑、删除和新增。
4. 确认梳理结果并进入完成页。
5. 刷新浏览器确认 localStorage 持久化。
6. 在桌面和窄屏宽度下检查布局。

## 提交前检查
- 功能没有破坏现有流程。
- 控制台没有运行时错误。
- lint 与 build 均成功。
- 文档与开发日志同步更新。
- 不提交敏感信息、API 密钥或用户真实冲突文本。
