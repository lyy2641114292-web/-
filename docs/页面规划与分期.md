# Between Us 页面规划与分期

## 核心理念
不替你定义关系，只陪你重新看见关系。

## 第一阶段已实现
- 首页与核心理念
- 事件描述
- 模拟结构化梳理
- 事实、主观判断、情绪、内在需求编辑
- 条目删除与新增
- 梳理确认与完成页
- 浏览器本地保存
- 响应式布局与进度指示

## 当前原型扩展范围
- 首页中的核心理念入口已可进入完整流程，含“静观”光点直达入口。
- 事件记录页为六层深挖式回溯：时间背景、对话原话、表情语气、反应与内心、错位与转折、情绪与需求；支持语音输入与图片补充。
- 情绪画布支持点击情绪碎片进入「情绪逐层探索」：背后感受多选 → 反思问题 → 需求识别（自动汇入内在需求）。
- 时间线回溯按节点阶段（冲突前/矛盾触发/冲突发生/关系变化）使用不同问题集，节点完成后点亮、保留独立进度，选项点击有记录反馈并自动进入下一问。
- 视角转换已重构为朋友视角与第三方“静观”双对话通道；本阶段使用本地模拟引擎（锚定事件细节），预留真实 API 开关。
- 视角对照与反思总结页面已移除，由静观收尾（关键发现 + 未知项整理）替代，结果展示于完成页。

## 第一阶段后续完善
- 首页
- 将现有完成页调整为完整反思流程入口
- 增加真实数据结构和 AI 接口能力
- 统一页面文案与导航

## 第二阶段：时间线回溯
页面内容：
- 冲突前
- 矛盾触发
- 冲突发生时
- 冲突发生后
- 关系变化

交互要求：
- 节点可点击。
- 每个节点展示事实、情绪变化和不确定信息。
- 节点切换保持上下文连续，不强行总结用户结论。

## 第三阶段：双视角转换
页面内容：
- 我的视角
- 对方可能的视角
- 当前视角切换滑块或拖动控制
- 假设依据与未知因素

交互要求：
- 对方视角始终标记为假设。
- 用户可以否定、保留或修改推测。
- 切换反馈细腻且可逆。

## 第四阶段：静观与收尾整理（已调整）
页面内容：
- 静观第三方观察对话（锚定事件具体细节，一次一个观察、一个问题）
- 收尾整理：关键发现与仍然未知的部分

交互要求：
- 不替代原“视角对照”独立页；未知区域在对话与收尾中以低对比、留白方式呈现。
- 用户可随时“完成回顾”进入收尾，也可“结束这次回顾”查看完成页。

## 第五阶段：反思总结与表达辅助（后续）
页面内容：
- 用户认识到的事实与情绪变化
- 当前内在需求
- 个人意愿选择
- 可选沟通表达草稿

交互要求：
- 用户始终自行选择下一步行动。
- AI 不替用户决定修复或结束关系。
- 草稿可编辑、保存或放弃，不自动发送。
- 当前版本该阶段由静观收尾替代，草稿能力留待后续恢复。
