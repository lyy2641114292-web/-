# Between Us 视觉与交互规范

## 视觉定位
整体采用温暖、安静、克制的编辑式设计风格，强调：
- 情绪陪伴
- 信息层次
- 沉浸式反思体验
- 细腻的节点、滑块和未知区域反馈

首页采用“沉浸式情绪地形叙事”风格：
- 深海蓝背景与缓慢变化的细线等高线。
- 少量珊瑚橙光点作为视觉焦点。
- 半透明渐变色块、模糊光团、碎片和细网格建立空间层次。
- 避免廉价科技感发光、过度紫蓝渐变和普通心理疗愈 App 卡片式布局。

首页探索光点：
- 光点是明确的章节入口，不作为纯装饰使用。
- 光点悬停显示章节名称，键盘焦点必须提供同等反馈。
- 已探索入口保留低对比光环痕迹。
- 光点点击使用短暂聚焦扩散，不使用长时间遮罩或高强度发光。
- 鼠标局部光照、粒子和地形视差只提供空间反馈，不影响文字识别。

不要把所有内容都设计成卡片。应根据内容类型选择时间轴、并排文字区、留白区域和轻量分栏。

梳理结果页应呈现为柔性的“情绪探索画布”，不能以卡片、四宫格或思维导图方式组织：
- 优先展示一至两个词或极短句，每条信息尽量短于一句完整复述。
- 信息允许以模糊光团、微小圆片和不完全对称的位置漂浮呈现。
- 不展示分类标题卡片、不重复事件概括、不堆叠长段说明。
- 中央保留“此刻”等低存在感空间提示，形成包容、不急于定论的情绪状态。
- 背景可使用细轨道、模糊光团、点状噪声和柔性连线，避免精确网格。

情绪地形贯穿产品：
- 首页、描述、梳理、时间线和双视角使用同一套深蓝、雾蓝、灰紫和低饱和珊瑚色语言。
- 时间线不是普通直线，应呈现为穿过等高线地形的探索路径；节点对应阶段、点击展开当前详情。
- 时间线节点悬停显示简短事件提示；选中节点放大并显示珊瑚色状态光，详情在同一页面侧边展开。
- 详情允许编辑事件名称、时间/阶段、具体经过、情绪、理解/判断和尚未补充的信息，不预填虚构事件。
- 时间线节点支持新增、删除确认和切换保留；删除后不得影响其他节点数据。
- 双视角像透明图层一样重叠、位移和显隐；拖动滑块时对应图层变化，未知区域保持模糊。
- 时间线、视角对照和反思页面在节点切换时整体淡入、位移和柔化展开，不在同一画面堆叠多个交互面板。
- 页面控件优先使用圆润胶囊形、曲线边界、柔和边线和低对比模糊，避免尖角卡片和强分割线。

## 色彩
主色：
- 深蓝：#101725、#172236、#1A2033
-雾蓝：#AEBED3、#9CA8C4、#7D9AB5
-灰紫：#A89AB9
- 温暖灰：后续页面可适度引入低饱和米灰色，避免冷色过重。
-珊瑚橙：仅用于少量强调节点、悬停焦点或关键状态。
- 未知区域：使用低对比、虚线边界或模糊感，不直接展示为确定结论。
-主文字：#EDF1F7
-次要文字：#AEB7C8

## 排版
- 中文使用 Microsoft YaHei 或 PingFang SC。
- 标题使用 Georgia 或系统衬线字体。
- 正文保持清晰层级，避免过度装饰。
- 分类标签使用小字号与字母间距增强识别。

## 布局
- 桌面端描述页采用左右分栏。
- 桌面端梳理页使用不对称碎片画布，不形成固定四栏。
- 中等宽度下碎片仍保持错落分布，不收缩为卡片网格。
- 移动端保持整屏画布，碎片错落排列并避免重叠和横向溢出。
- 页面使用半透明面板、细边框、淡网格和柔和光晕。

## 交互反馈
- 不可提交状态降低按钮透明度并禁用。
- 可删除条目悬停时显示删除图标。
- 新增按钮在输入为空时禁用。
- 阶段切换使用淡入动画。
- 加载状态使用旋转指示器和禁用提交按钮。
- 时间线节点必须可点击，并清楚反馈当前节点状态。
- 视角切换应使用连续、可预览的拖动或滑动反馈。
- 未知区域应避免警示色和强阴影，突出“不确定”而不是“缺少答案”。
- 对方视角中的文本必须标注为假设或可能性。

## 文案原则
- 使用第二人称或中性表达。
- 不使用“你应该”“你错了”“对方做错了”等评判性措辞。
- 保持温和、开放、非诊断化语气。

## 引导式回溯
- 事件描述入口先提供“一两句话概括整件事”的明确区域。
- 概括之后，以轻量关键词浮标呈现可回忆线索，浮标可直接进入对应引导层。
- 关键词浮标不能替代自由描述；自由描述提示栏始终可见且可直接使用。
- 每次只呈现一个核心问题，避免一次要求用户回忆全部信息。
- 引导语区分“事实”“反应”“判断”“感受”“需求”，但不使用指责或审判语气。
- 示例必须标注为示例，不得表现成唯一答案。
- 用户可跳过、返回修改或直接进入下一层。
- 引导卡片优先使用提示、留白和细边框，不堆叠多重装饰卡片。

## 时间线探索与逐层回溯
- 时间线使用可拖动视野、地形等高线、主路径和悬浮节点建立探索感。
- 鼠标拖动和触摸拖动只作用于探索空间背景；节点点击不得触发拖动。
- 提供回到原点入口和拖动操作提示。
- 节点悬停显示简短关键词；已确认、待补充和未知节点使用不同边线或中心状态。
- 点击节点进入同一阶段内的全屏式逐问题回溯，不将表单直接铺在地图上。
- 每次只展示一个核心问题，优先关键词选项，文本输入仅用于补充。
- 回溯页面提供返回修改、跳过/不确定、继续和新增/删除节点入口。

## 视角场景
- 视角转换按时间线节点逐个进入，不使用并排信息卡片作为主要结构。
-视觉小说场景以左右圆润气泡呈现真实确认的友方与用户内容；说明、档案和辅助面板不得占据主要画面。
-朋友未确认的原话或反应使用模糊气泡、未知提示或留白，不可虚构。
- 确认事实、假设区域、未知区域必须视觉和文案分区。
- 观察位置滑块改变透明度和空间位移，而不是责任占比。
- 对方可能注意到的内容仅通过假设关键词或明确未知选择表达。

## 深挖式回溯与细节补充
- 引导回溯按六层推进：时间与关系背景、具体对话过程（原话）、表情与语气、反应与内心、错位与转折、情绪与需求；每层一个核心问题，可跳过、返回修改。
- 示例必须标注为示例，不得表现成唯一答案；选项可多选、可自行描述。
- 语音输入使用麦克风胶囊按钮，聆听时以珊瑚色脉冲提示；不可用时降级为文字提示，不阻塞手动输入。
- 图片补充以本地缩略图呈现（每层最多 3 张），可随时移除；图片仅作回忆辅助，不自动生成描述。

## 时间线节点点亮
- 每个节点按阶段使用不同回溯问题，进度以节点外圈进度环呈现。
- 节点全部回溯完成后“点亮”：珊瑚色光晕 + 标签「已点亮」；刚完成时播放一次短暂的光晕扩散动画。
- 点击选项立即出现“已记录”反馈并自动进入下一问；已记录选项保持选中态，可再次点击修改。
- 已完成节点再次进入时显示「已点亮」提示条，可逐题回看或修改，不要求重答。

## 情绪逐层探索
- 点击情绪碎片进入整页逐层探索：第一层「背后感受」多选（可自定义），第二层「反思问题」自由书写，第三层「需求识别」映射出需求候选（可补充），确认后汇入内在需求。
- 探索过的情绪碎片显示低饱和灰紫边线与「→ 需求」连接提示；进度以三个细节点表示。
- 逐层推进使用柔和淡入，不弹卡片遮罩；返回画布保留未完成的探索内容（不保存未确认结果）。

## 静观收尾
- 静观对话保持一次一个观察、一个问题；收尾时以短段落整理关键发现与未知项，未知项使用低对比表达。
- 完成页展示静观整理结果，提供「返回静观」与「开始新的梳理」，不催促用户做决定。
